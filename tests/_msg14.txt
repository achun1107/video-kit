feat: 内容质量（真卖点替代目录名）

## 问题

四条片子念的都是「出图与创作、开源工具与 DSH 插件、找命令行工具」——
这些是 README 的目录名，不是卖点。念出来观众不知道这玩意儿能干嘛。

## 根因

extract-content.mjs 从 README 抽 features，抽到的是某个目录列表。
但 README 里其实全是真卖点：

  > 你只说话，Agent 搞定一切。不需要懂代码、不需要懂命令行。

  > 「AI 编程要花多少钱」是小白第一个会问、也最容易误解的问题。
  > 很多人以为必须订阅 Claude Code 或 Codex，于是还没开始就劝退了。
  > 装上 magpie：用免费模型额度，一分钱不花让 Agent 干活。

  > 已经卡住了 → 直接问客服，答疑不收费。

这四条能打动人：零门槛、零成本、全流程、有人兜底。

## 改法

手写 content.json（自动抽取做不到这一步）：

  headline   你只说话，Agent 搞定一切
  features   说人话就行，不用碰代码
             白嫖模型额度，一分钱不花
             从 0 到发布，全程有人带
  conclusion 全免费 / 不用懂代码 / 有人答疑

features 去掉了「零门槛：」这种前缀 —— 冒号念出来会卡一下，
节奏被切碎。

## 流程上的教训

自动抽取只能给素材，卖点要人来提炼。
正确流程是：自动抽 → 人工改 content.json → 再出片。
这件事写进 content.json 的注释里了。
