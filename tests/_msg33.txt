feat: 选题评估工具（tools/score-repo.py）

## 为什么做这个

25 轮下来，工作流能把画面做到很精致。但有个更根本的问题：

**项目本身没吸引力，天花板就在那里。**

133 星的小工具，画面再好也难火。做视频前该先问一句：
这项目值得占我 30 秒吗？

## 评分维度（满分 10）

  star 数      0-3   社会证明。1000+ 才有点话题性，100 以下基本没戏
  活跃度        0-2   最近一个月有新 commit 说明还活着
  可视化        0-2   有 Demo / 有界面 / 前端项目就好做，纯 CLI 很难出画面
  一句话说清    0-2   description 能不能让人秒懂（10-60 字最佳）
  赛道热度      0-1   AI / 效率工具 / 爬虫 比 "个人博客模板" 有流量

## 实测结果

用三个不同量级的项目验证：

  heygen-com/hyperframes     10.0/10  → 值得做
  vercel/next.js              8.9/10  → 值得做
  webkubor/xiaobai-kanban     5.6/10  → 能做，但要找独特角度

我们自己做的这个项目，明细：

  star 数     0.6/3   134，太少
  活跃度       2.0/2   一周内有更新
  可视化       2.0/2   有 Demo + 前端项目
  一句话说清   0.5/2   121 字，太长
  赛道热度     0.5/1   有 ai 但也有 tutorial

**5.6 分说明：视频做得再好，也就是个及格线的选题。**

工具没在安慰人 —— 它直接告诉你这个项目不值得投入太多精力。

## 用法

  python tools/score-repo.py owner/repo
  python tools/score-repo.py a/b c/d e/f     （批量对比会排名）
