fix: 清掉模板里的"假话"（照抄参考视频的文案）

## 这轮发现的问题最严重

审计模板里写死的中文文案，发现 ganhuoju 有 6 句、weitu 有 3 处
是照抄参考视频（Scrapling / Agent Desktop）的：

  ganhuoju：
    「这款工具最厉害的地方」
    「不管怎么变」「它都能自动适配」
    「全程不用改代码」「新手也能上手」

  weitu：
    代码块 `$ tool snapshot` / `tool.snapshot()`
    「支持 macOS · Windows · Linux」

## 为什么是问题

小白看板是个**教程网站**，不是爬虫工具，也不是桌面自动化工具：

  · 「不管怎么变都能自动适配」—— 跟它没关系
  · 「全程不用改代码」—— 它本来就教人写代码，这是**假话**
  · 有命令行？搜不到。观众会取关

模板污染：参考视频的文案被写死进模板，换个项目就变成假话。

## 改法

1. ganhuoju 的 card4/card5 改成读 FEATURES[1] / FEATURES[2]，
   标题改成中性的「第二个亮点」「第三个亮点」
2. card3 的「这款工具最厉害的地方」→「它到底能干什么」
3. weitu 的 card3 整段重写：不再画假代码块，
   改成 macOS 窗口里列三个真实能力（读 FEATURES）
4. weitu 页脚的「支持 macOS · Windows · Linux」删掉

## 顺带修：特性卡文字被截断

weitu card4 里 `String(t).slice(0, 10)` 把 11 字的
「说人话就行，不用碰代码」截成了「…不用碰代」。
去掉 slice，让 featureCard 的字号自适应处理宽度。

第一版字号用 fr.measure 算，量出来偏小导致仍然溢出。
改成按字数直接算：tsize = (w - 44) / 字数，限制 16~30。
