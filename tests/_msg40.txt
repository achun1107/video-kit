量四条片子前 2 秒的画面变化率（相邻帧像素差异）。

  ganhuoju  26.0 / 24.2 / 4.1 / 8.3  合格（第 32 轮修过）

  weitu      4.9 / 0.3 / 0.3 / 1.0   ★几乎静止★

xiaokai 和 weitu 的 card1 全是 a:1 硬切 —— 和 ganhuoju 原来的问题一样。

## 修 xiaokai

  star 数字   0.00-0.45  放大 + 提亮 + 持续呼吸（0.97~1.03，周期 2.4 秒）
  标题两行     依次滑入，第一行 0 秒起 alpha 0.65 起步
  整块上浮     1.2 秒后以 22px/秒缓慢上浮

踩的坑：titleCard 的白底用了 a=1，但文字用 a*lineIn，
第 0.1 秒出现「白框已出来、字还没出现」的空框。
改成白底透明度跟随第一行。

结果：10.2 / 2.2 / 3.5 / 4.3 → 偏静（极简网格风格，可接受）

## 修 weitu

原来 0.1 秒时画面只有「开源项目」胶囊，**标题一个字都没有**，
90% 是空的深蓝背景。

改成第一行标题从 0 秒起、alpha 0.65 起步。

结果：
  D 项从 0.4% 亮点 → 3.9% 通过
  动感 3.6 / 2.9 / 0.9 / 1.0 → 仍偏静

**weitu 这项没修完**：它是深蓝渐变 + 纯文字版面，
没有大块图形元素，像素变化率天然低。
文字在动但占比小。下轮加背景动效解决。
