feat: 运营视角补齐发布链路（安全区 / 封面 / 文案 / 发布包）

之前的工作流只做到"渲出一个 mp4"。从运营角度看，这样发不出去 ——
视频会被平台 UI 挡、没有封面、没有标题和话题、文件散落在工程目录里。

这轮补了四块。

## 1. 平台安全区（最致命的）

四条片子的字幕都在 Y=1620~1700，而抖音底部 UI 遮挡到 Y≈1420。
发出去字幕会被文案区、音乐条、进度条挡住，等于没有字幕。

各平台竖屏遮挡（1080×1920）：
  抖音     底部 ~480px + 右侧 ~200px   ← 取这个当标准
  小红书   底部 ~360px + 右侧 ~180px
  视频号   底部 ~300px + 右侧 ~180px
  B站竖屏  底部 ~300px + 右侧 ~180px

四套模板的字幕统一移到 Y=1330（安全区内，离底 90px 余量），全部重渲。

## 2. 封面生成（tools/make-cover.py）

发布时四个平台要传不同尺寸的封面：
  抖音 1080×1920 / 小红书 1080×1440 / 视频号 1080×1260 / B站 1080×1920

踩了三个坑：
  · 第一版抽视频帧 + 叠标题 → 图上出现两套标题（抽的帧本身就有字）
    改成不抽帧，用 content.json + 干净的 GitHub 截图重新排版
  · 手写体字距比黑体大，"小白看板"四个字占 700px
    改成按实际字宽自适应字号
  · 数据条用 min() 算位置，正好压在截图底部
    改成必须落在截图下方

star 从 API 补 —— extract-content.mjs 只读本地 README，拿不到 API 数据，
封面没有 star 就少一个最强的信任背书（"133 ★" 比"完全开源"具体得多）。

## 3. 发布文案（tools/publish-info.py）

四个平台的标题/话题/简介风格不同：
  抖音     短标题 + 钩子 + 3-5 个话题
  小红书   种草语气 + 分段正文 + 5-8 个话题
  视频号   稳，不加 emoji，2-3 个话题
  B站      可长，标签走 tag 系统

功能点过滤做了两道闸：
  · 排除受众句式（「给真人（小白）」这类是"适合谁"，不是"有什么功能"）
  · 必须有功能动词（「出图与创作」这种名词短语是分类名，跳过）
过滤后为空就跳过那一段，不写废话兜底。

## 4. 一键发布包（tools/make-package.py）

一个目录拿走就能发：

  D:\publish\<风格>/
    01_成片.mp4
    02_封面-抖音.png / 小红书 / 视频号 / B站
    03_发布文案.md
    怎么发.txt        ← 各平台的注意事项清单

## 同一项目发多条时标题必须不同

四个模板渲同一个项目，标题一开始完全一样（「133 星的冷门开源项目」）。
平台会判重复内容限流，关注的人看到四条一样的直接划走。

加 --style 参数，每个风格用各自的钩子池：
  ajin      手把手带你看这个开源项目
  ganhuoju  133 星的项目，我给它划了重点
  xiaokai   又挖到一个宝藏开源项目
  weitu      刚开源就火了

ruff All checks passed / 60 测试全过 / 10 个外链可达。
