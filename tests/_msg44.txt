fix: 用户反馈「插图少了、字体丑了」

## 用户原话

「我看了下，设计出来的，比原先还难看，插图少了、字体丑了」

## 查证了两个真问题

### 1. 字体丑：两行大字变成一行标签 + 两行小字

对比最早版本（commit 4b342ba）：

  原版 card4
    「不管怎么变」      110px 大字
    「它都能自动适配」   96px 大字

  改坏之后的 card4
    「第二个亮点」       84px 小标签   ← 我加的机器味标签
    features 拆两行      72~86px

**字号砍半，手写体的气势全没了。**

修法：去掉编号标签，features 按逗号拆成两行，字号回到 104 / 88。

  白嫖模型额度，一分钱不花  →  「白嫖模型额度」104px + 「一分钱不花」88px
  从 0 到发布，全程有人带    →  「从 0 到发布」100px + 「全程有人带」88px

文字仍然全部来自 features（不撒谎），但气势回来了。

### 2. 插图少：截图只占画面 36% 高度

bed() 用 contain 完整显示截图，宽 W*0.94 = 1015px。
GitHub 截图约 1.46:1，算下来高度只有 695px。

**画面高 1920px，截图只占 36%，上下 64% 是深色空底。**
而且 6 张卡都用同一张图、同一位置，看起来像 PPT 换文案。

修法：给 bed() 加 region 参数，每张卡放大显示截图的不同部位：

  card1  顶栏（项目名 + star）
  card2  底部（commit 记录）
  card3  中间（README 正文）
  card4  左侧（文件列表）
  card5  右侧（About 侧栏）
  card6  完整图（收尾）

裁剪比例都调成接近方形。第一版用「全宽 + 窄高」（top 取 28% 高度），
算出来是 5:1 的扁条，放大后反而更小更空。

## 过程中的两个教训

1. 改 card4/card5 时我用括号配对找函数结尾，替换成功了，
   但「第二个亮点」作为 fallback 字符串还留在代码里，
   检查时误以为没生效。

2. 打包后一直在抽 publish 包里的旧 mp4 看效果 —— 那个文件是 12:54 的。
   真正改好的 final.mp4 是 13:43 的。
   验证要认准时间戳，不能只看路径。
