fix: 循环 BGM 的接缝（Carefree 首尾差 6.7dB 会爆音）

## 问题

上轮把 BGM 改成循环，但没检查接缝。

用 tools/check-bgm-loop.py 量了四首 BGM 的首尾电平：

  Carefree          -30.1 / -23.4 dB   差 6.7 dB  ← 会爆音
  Life_of_Riley     -23.1 / -24.0 dB   差 0.9 dB  可以
  Fluffing_a_Duck   -14.1 / -17.5 dB   差 3.4 dB  可以
  Wallpaper          -6.6 /  -6.5 dB   差 0.1 dB  完美

Carefree 首尾差 6.7 dB，硬循环会在接缝处产生可听的音量跳变。
ajin 用的正是这首。

## 改法

本想改 mix.py 加预处理，但两次插入辅助函数都破坏了缩进
（第一次插进 main() 内部导致函数没 body，第二次删错段导致
def sopt 缩进错乱）。git checkout 回滚 mix.py。

改用更简单的方案：**直接生成一个首尾淡化的 BGM 文件**。

  Carefree-looped.mp3 = Carefree + 首尾各 0.12 秒淡入淡出

验证：
  原版    首 -30.1 dB  尾 -24.8 dB
  淡化版  首 -39.9 dB  尾 -35.5 dB   ← 都接近静音，接缝听不出来

## 验证

ajin 重混后分段测音量：
  2-6s    -19.6 dB
  16-20s  -19.3 dB
  30-34s  -19.8 dB     ← 三段一致，后半段有音乐

## 教训

改一个 200 行的脚本时，用字符串替换插函数容易破坏缩进。
应该直接用 edit 工具定位到具体行，或者先看完整结构再改。
