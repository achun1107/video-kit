# 怎么说清需求

这份文档不是给开发者的，是给**用这个工具做视频的人**。

你不需要会跑命令。把下面这两样东西给 AI 助手（Claude Code / Cursor / Copilot / 你自己跑），
它就出一条片子。

---

## 最小输入：一个链接

```
https://github.com/owner/repo
```

或者抖音分享文本，原样粘：

```
3- 长按复制此条消息，打开抖音精选搜索… https://v.douyin.com/xxxxxx/
```

只给链接也能跑，但**出来的文案是套话**（见下面「真实案例」）。所以最好加上第二样东西。

---

## 加上一句话卖点

这句是唯一自动不了的部分。它决定：

- 封面写什么
- 三个标签写什么
- 哪 4 个特性被选中

| 你说的 | 出来的效果 |
|---|---|
| 「这是我做闲鱼自动化用的底层库，特点是限流和工作流引擎」 | headline = 限流 + 工作流，特性往这个方向挑 |
| 「八万星那个 HyperFrames，写 HTML 出视频的」 | headline = 写 HTML 出视频，数字墙放 80,464 |
| 「Bloom 主题，15 套中国色那个」 | headline = 中国色配色，色块墙当主视觉 |

---

## 完整模板

```
帮我把 https://github.com/xxx/yyy 做成视频。
卖点：一句话让 AI 接管浏览器
重点讲：多进程锁、请求限流、能跳过验证
受众：同行，可以讲技术细节
时长：30 秒左右
```

多写不亏。写清楚的都能用上，没写的就靠猜。

---

## 更省事：报个名字就行

如果你在说的东西我这边有记录，只报名字也能开工：

```
用 xiaobai-kanban 那个模式，做一下 xxx 仓库
```

## 什么会自动做

| 步骤 | 说明 |
|---|---|
| 克隆 / 下载仓库 | 大仓库走 API，避免 180 秒 clone 超时 |
| 截 GitHub 页面 | 带聚焦坐标，给「放大圈选」用 |
| 抽 star 数、功能列表 | 依赖 README 的标题结构 |
| 配音 | 微软云希，男声，+45% 语速 |
| 字幕 | 从配音的 SRT 来，误差 0 |
| 七张卡排版 + 动画 | 封面 / 数字墙 / 截图 / 特性 / 亮点 / 清单 / 结论 |
| 配乐 + 混音 | 人声领先配乐 19.2 dB |
| 渲染 | 1080×1920 / 30fps / 34.8s |
| 生成播放页 | 单文件，双击就播 |

---

## 什么要你定

| 事项 | 为什么 |
|---|---|
| **文案** | 模板稿永远是套话，只能说「把最要紧的东西摆出来了」 |
| **主打哪 3 个功能** | 仓库可能有 10 个特性，视频只放 4 个 |
| **给谁看** | 同行看技术细节，外行看能干什么，讲法完全不同 |
| **要不要真人出镜** | 现在是纯 TTS 配音，没有人脸 |

## 真实案例：一次翻车

拿这个仓库自己试跑：

```
输入  https://github.com/achun1107/xianyu-kit
输出  1080×1920 / 34.8s / 8.2 MB
```

**流程全跑通了，但文案是空的：**

> 「一个开源项目。这个叫 xianyu-kit 的开源项目，把最要紧的东西都摆出来了。
> 先从它是什么讲起，再一条条拆给你看。不用注册，不用订阅，装好就能用。」

**为什么失败**：自动抽取器依赖 README 的标题结构（`## 特性`、`## 快速开始` 这类固定小节名），
而 `xianyu-kit` 的 README 用的是 `## 安装`、`## 工作流`，对不上，抽出来就是空的。

**教训**：

- 流程能自动跑完，**不等于内容能用**
- README 写得规整的仓库（有 `## Quick Start` / `## Features`）抽取效果最好
- 没抽到内容时，加一句卖点重跑，比改 README 快

## 什么情况该放弃自动抽取

直接手写 `audio/copy.json`：

```bash
# 出片后改这个文件
vim <工程目录>/audio/copy.json
# 重新配音
python tools/tts.py <工程目录>
```

```json
{
  "voice": "zh-CN-YunxiNeural",
  "rate": "+45%",
  "pitch": "+5Hz",
  "vo1": "第一段（约 20 秒，110-130 字）",
  "vo2": "第二段（约 10 秒，60-80 字）"
}
```

改完重跑 `tts.py`，字幕时间轴自动跟着变。

**两段文案的分工**：

- `vo1`（0-21 秒）：钩子 → 是什么 → 三个亮点 → 数字
- `vo2`（21-34 秒）：怎么用 → 结论

字数和时长是对应的：7 字/秒 × 时长。

## 做不了的

| 事项 | 原因 |
|---|---|
| 发到抖音 / B站 | 需要你的账号登录 |
| 判断什么内容会火 | 那是选题，不是制作 |
| 真人口播 | 现在只有合成语音 |
| 超过 35 秒的片子 | 七张卡是固定的，做长篇要改模板 |

---

## 一句话总结

**给链接 + 一句话卖点，剩下的交给它。**

想更省事就只给链接，但要有心理准备：文案会像产品说明书。
