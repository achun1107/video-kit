# 冷门视频对比：为什么同样结构，数据差 275 倍

抓取时间：2026-11-09
方法：和爆款同一套逐帧采样，看冷门视频差在哪

---

## 一、对比样本

| 编号 | 标题 | 赞 | 收藏 | 时长 | 画面数 |
|---|---|---|---|---|---|
| A | Codex GSAP 复刻苹果官网UI | **1.1万** | 1.2万 | 51s | 6 |
| B | Codex 两大必装设计 Skill | **7089** | 7481 | 34s | 5 |
| C | 多模型调用神器本地压缩省 Token | **40** | 17 | 38s | 5 |
| D | AX短剧外挂 83个短剧skill | **1** | 26 | 47s | 5 |

---

## 二、结构完全一样

四条视频的画面结构**没有任何区别**：

```
[真人头像]   固定标题栏
──────────────��───────────
       5~6 个画面切换
──────────────────────────
     超大白色字幕
```

- 都有真人头像（圆形，左上角）
- 都有固定标题栏（右上角，全程不动）
- 画面数量都是 5~6 个
- 字幕都是超大白色
- 都有「内容由 AI 生成」声明

**所以结构不是决定因素。** 这一点很重要——不用再纠结排版。

## 三、真正的分界线：画面里有没有 GitHub 页面

| 视频 | 画面内容 | GitHub 页面数 | 赞 |
|---|---|---|---|
| A | 彩色渐变 / 白色网页 / 3D 人物 / 黑色终端 / 紫色场景 / 产品页 | **0** | 1.1万 |
| B | 图标组合 / 白卡片 / 聊天窗 / 代码配置 / 3D 场景 | **0** | 7089 |
| C | GitHub 卡片 / 设置界面 / GitHub 页面 / 设置界面 / 3D 卡通 | **2** | 40 |
| D | GitHub About / GitHub 文件列表 / **GitHub 搜索 / GitHub 标签 / GitHub 文件** | **5** | **1** |

**GitHub 页面出现得越多，数据越差。这条对应关系非常干净。**

---

## 四、为什么

观众刷到一条 AI 工具视频，想知道的是「**这东西能做出什么**」。

- A：GSAP 能做出丝滑动效 → 我看到动画了 → **存下来**
- B：Taste 能提升设计质感 → 我看到设计作品了 → **存下来**
- C：能省 Token → 我看到的是设置界面 → **省 Token 跟我有什么关系**
- D：83 个短剧 skill → 我看到五个 GitHub 页面 → **我不知道这些 skill 长什么样**

**GitHub 页面是「原料」，不是「成果」。**
原料对作者有意义（我知道它开源、多少星），对观众没意义。

---

## 五、这条结论直接否掉了我们的方向

我们四条片子的画面，全部是 **GitHub 仓库页面的不同裁剪**。

按这张表推断，预计数据会落在 C 和 D 之间（40 赞 ~ 1 赞区间）。

**不是排版不好看，是「可看的东西」选错了。**

---

## 六、那什么才是「成果」

| 内容类型 | 例子 | 可展示的成果 |
|---|---|---|
| 动画 / 动效 | GSAP、Remotion | 逐帧的动画效果 |
| 设计 / UI | Taste、Impeccable | 设计稿、落地页 |
| 图像生成 | 生图模型、无限画布 | 生成的图 |
| 视频生成 | Seedance、Hyper | 生成的视频片段 |
| 3D / 建模 | Blender 联动、CAD | 3D 模型旋转 |
| 游戏 | 像素特效库、游戏引擎 | 游戏画面 |

**共同点：产出物本身是「看得见的东西」。**

反过来，这些做不出好数据：

| 内容类型 | 为什么 |
|---|---|
| 省 Token / 省钱 | 成果是"成本降低"，看不见 |
| 教程 / 入门指南 | 成果是"你会了"，要等很久 |
| 工具合集 | 成果是"知道有这么个东西"，没有画面 |
| Chrome 插件 | 界面变化小 |
| CLI 工具 | 只有终端文字 |

**我们的项目是「AI 编程入门教程」**——落在最差的那一栏。

---

## 七、能立刻改的三件事（不改代码）

### 1. 换选题（最根本）

选一个「产出物看得见」的项目。判断标准一句话：
**能不能截出 5 张完全不同的、观众看得懂的画面？**

不能，就不做。

### 2. 如果必须做当前项目

唯一能放的是**「用这个教程做出来的东西」**——
比如"跟着它三天做出的第一个网页"，而不是"这个教程讲了什么"。

**把教程变成成果。**

### 3. 加固定标题栏

爆款和冷门都有，我们四条都没有。
成本极低（一行小字常驻右上角），收益是"划到一半进来的人能立刻接上"。

---

## 八、一句话总结

**爆款和冷门的结构一模一样，差别只在「镜头里有没有成果」。**

排版、字体、动效、时长，都不是决定变量。
