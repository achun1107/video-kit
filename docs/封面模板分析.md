抓取时间：2026-11-09
方法：截图主页封面网格，逐屏看

## 一、封面模板（264 条全部一致）

```
┌────────────────────┐
│ ╭────────────────╮ │  ← 紫色虚线边框
│ │  白色粗体标题    │ │     2 行，每期不同
│ │                │ │
│ │ ▶ 绿色箭头      │ │  ← 黄绿色副标题
│ │   副标题        │ │     半句卖点
│ │                │ │
│ │  [3D 卡通人物]  │ │  ← 每期不同姿势
│ ╰────────────────╯ │
│ ♡ 1.8万            │  ← 左下角点赞数
└────────────────────┘
```

### 五个固定元素

| 元素 | 是否变化 |
|---|---|
紫色虚线边框 | **固定** |
深色背景 | **固定** |
白色粗体标题（2 行） | 每期不同 |
绿色箭头 + 黄绿副标题 | 位置固定，文字不同 |
3D 卡通人物 | 每期不同姿势 |
左下角点赞数 | 自动显示 |

**264 条作品，零例外。**

## 三、封面的真实作用：账号识别

刷到这个号的任意一条，一眼能看出：

1. **紫色虚线框** → 这是 AI科技视野
2. **绿色箭头** → 这是他的固定版式
3. **3D 卡通人物** → 这是他的视觉锤

**这解决了一个我们之前没意识到的问题：**

我们做了四套完全不同风格的封面（ajin 荧光笔 / ganhuoju 手写 / xiaokai 网格 / weitu 深蓝），
**观众刷到不会认为是同一个人的作品**。

**账号识别是复利，四条片子四种风格是减法。**

---

## 四、两层都要模板化

这个账号的做法：

| 层 | 做法 | 作用 |
|---|---|---|
**封面** | 紫色边框 + 标题 + 3D 人物，264 条统一 | 账号识别 |
**视频内** | 真人头像 + 固定标题栏 + 5~6 画面 + 大字幕 | 观看体验 |

**两层都是固定模板，只换内容。**

不是"每期重新设计"，而是"每期往模板里填东西"。

## 五、对我们的启示

### 现在的问题

| | 我们 | 他 |
|---|---|---|
封面 | 4 种完全不同风格 | 1 种模板 |
片内结构 | 4 种（荧光笔/手写/网格/深蓝） | 1 种（真人+标题栏+大字幕） |
账号识别 | **无** | 极强 |

### 应该做的

**收敛成一套。**

不是四套风格并行，是**一套视觉系统**：
- 固定封面模板（边框 + 标题位置 + 人物/图标位置）
- 固定片内结构（标题栏位置 + 字幕样式 + 画面切换节奏）
- 每期只填：标题文字、画面素材

**四套风格可以留作"内容类型"的区分（教程/工具/评测），但不能每套视觉都不同。**
