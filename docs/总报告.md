## 七、结论

### 一句话

**形式（结构、节奏、排版、时长）早就够了，问题是镜头里没有成果。**

### 三条能立刻做的

**① 选题硬标准（30 秒判断）**

> 能不能截出至少 1 张「观众会想我也想要」的画面？
> - 5 张以上 → 大概率爆
> - 1 张 → 几百赞
> - 0 张 → 别做

**② 加固定标题栏**

爆款和冷门都有（右上角常驻一行），成本极低。
收益：划到一半进来的人能立刻知道在讲什么。

**③ 加收藏钩子**

收藏率是这类内容的命脉（爆款 100%~109%）。
口播里加一句"建议收藏，以后用得到"，一句话的事。

### 一个不能做的事

**我们的项目是「AI 编程入门教程」——按这张表，落在最差的「0 张成果画面」那栏。**

用这个项目做视频，做多少轮优化，天花板都在几十赞。

### 如果必须用这个项目

**唯一可行：把"教程"变成"成果"。**

- ❌ 讲教程有什么内容 → 观众看到 GitHub 页面
- ✅ 跟着教程做出来的第一个网页 → 前后对比
- ✅ 零基础 3 天做出来的东西 → 直接展示成品

**观众要看"学完能做出什么"，不是"教程讲了什么"。**

## 八、什么样的选题有成果画面

| 能做 | 为什么 |
|---|---|
| 动画 / 动效（GSAP、Remotion） | 逐帧效果本身就是成品 |
| 设计 / UI（Taste、Impeccable） | 落地页、设计稿 |
| 图像生成 | 生成的图 |
| 视频生成（Seedance、Hyper） | 视频片段 |
| 3D / 建模 | 旋转的模型 |
| 游戏 | 游戏画面 |

| 做不出 | 为什么 |
|---|---|
| 省 Token / 省钱 | 成果是"成本降低"，看不见 |
| 教程 / 入门指南 | 成果要等很久才出现 |
| 工具合集 | 每个工具都没深入展示 |
| Chrome 插件 | 界面变化小 |
| CLI 工具 | 只有终端文字 |

**判断方法：想象这条视频要剪 6 个画面，能不能每个都不一样、且都是"成品"？**
