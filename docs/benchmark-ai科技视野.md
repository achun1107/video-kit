## 二、反直觉的三条结论

### 1. 标题长度无差异
爆款平均 33 字，冷门平均 34 字。**不是"短标题更好"。**

### 2. 标签数量无差异
爆款 5.0 个，冷门 4.7 个。**不是"标签多更好"。**

### 3. 含数字反而更差
爆款 15%，冷门 27%。**数字不是钩子** ——
这一点和常见运营教程说的相反。

---

## 三、真正有效的三条

### 1. 问句（几乎翻倍）
爆款 19%，冷门 10%。

爆款例子：
- 「Codex 做网页动画像 PPT？」（1.1万）
- 「谁能拒绝一个会陪你敲代码的 Codex 宠物呢？」（5455）
- 「用的越久消耗 Token 越少？」（527）
- 「不限次数完全免费的 AI 生图网站？」（3830）

**问句的作用是做"预设对比"**：观众心里有个默认答案，
你用问句把它勾出来。

### 2. 具体工具名（不是"AI 工具"）
爆款 Top 15 里，**10 条都点了具体名字**：
GSAP / Taste / Impeccable / Product Design / Seedance / Claude / 豆包

反面：冷门里大量「这个开源项目」「一个工具」「某个 Skill」——
**观众不知道是什么，就不点。**

### 3. 具体产出（不是"很强""好用"）
- 「一键产出专业**丝滑动效**」
- 「一键生成**高颜值网页**」
- 「一键生成可编辑**分层 PSD 海报文件**」
- 「最高减少 **92%** Token 消耗」

**都是可以"看见"的结果。**

## 四、爆款标题的实际公式

```
[具体工具名] + [做某事像 X？] + [具体方案/Skill名] + [具体可看见的产出]
```

实例：
```
Codex 做网页动画像 PPT？
GSAP 官方 AI 动画 Skill，
一键产出专业丝滑动效！
```

```
Codex 网页开发全套技能组合！
四大 Skill 覆盖视觉、动效、代码、网页自动化测试！
```

## 六、我们现在的做法差在哪

| 维度 | 对标账号 | 我们 |
|---|---|---|
| 画面 | 真实录屏 + 真人 | 排版卡片 + GitHub 截图 |
| 标题 | 具体工具名 + 对比 + 产出 | 「小白看板，你只说话…」 |
| 时长 | 28–51 秒 | 34.8 秒（够） |
| 系列 | 「第 11 集」 | 「第 1 个开源项目」（弱） |
| 字幕 | 超大 | 已改到 52-57px（接近） |
| 收藏/分享 | 收藏≈点赞（1.2万 vs 1.1万） | 未知 |

**收藏数几乎等于点赞数** —— 说明内容是"要存下来以后用"的工具型内容，
不是"看完就过"的娱乐内容。这是知识类账号的核心指标。

---

## 七、工作流能改的和不能改的

### 能改（这一轮就做）
1. **标题公式**：加"像 X？"的对比钩子 + 强制点名具体工具
2. **文案骨架**：从"介绍项目"改成"展示能力"
3. **系列感**：把「第 1 个开源项目」改成更强的「第 N 集」

### 不能改（需要人）
1. **真人出镜** —— 只能你本人来
2. **真实录屏** —— 需要实际操作过程，脚本自动化做不出"手感"
3. **选题本身** —— 133 星的项目 vs 对标账号讲的 Codex/豆包等热门工具

---

## 八、结论

**排版再精致，也补不上"真人 + 真实画面"的差距。**

但标题公式是纯文本层面的，可以立刻改，而且数据显示问句和具体工具名
能把爆款率从 10% 提到 19%~33%。

这一轮的改进重点：**文案公式对齐爆款，不再堆画面细节。**
