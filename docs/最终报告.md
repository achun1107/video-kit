| 版本 | 结论 | 被什么推翻 |

| 1 | GitHub 页面越多，数据越差 | 537 赞那条有 3 个 GitHub 页面却不算差 |

## 四、最终结论

### 一句话

**画面里得有「正在发生的事」。**

### 五个档位的验证

| 视频 | 赞 | 画面 | 有"正在发生" |
|---|---|---|---|
| ChatGPT 隐藏功能直达 PS | **1.8万** | 5 个 ChatGPT 对话界面 | ✅ 对话在滚 |
| Codex 电脑全自动 | **1.6万** | 1 概念图 + 4 代码/终端 | ✅ 代码在写 |
| Codex GSAP 复刻苹果官网 | **1.1万** | 6 个动画/成品 | ✅ 动画在放 |
| Codex 网页开发 Skill | **1.1万** | 5 个成品 | ✅ 页面在生成 |
| AI 全能搞定前端运营 | **1.1万** | 5 个代码/Logo 动画 | ✅ 代码在滚 |
| Ian 小黑插画 | **537** | 3 个 GitHub 页面 + 1 插画 | ❌ 静态 |
| 70 行核心代码封神 | **199** | 代码截图 + 高亮圈 | ❌ 设计过的静态 |
| 多模型省 Token | **40** | 设置界面 | ❌ 静态 |
| AX 短剧 83 skill | **1** | 5 个 GitHub 页面 | ❌ 静态 |

**5/5 的 1 万+ 全部有「正在发生」。**
**所有低分的都是静态。**

### 为什么「正在发生」比「成果」更准

成果是**名词**（一个东西），正在发生是**动词**（一件事）。

- 看到**东西** → "哦，有这么个东西" → 划走
- 看到**事在发生** → "他在干嘛？" → 停下来看

**好奇比好看更能留住人。**

### 为什么 GitHub 页面是负分

信息密度最高、动态最少。**既不好看，也不在动。**

## 五、标题层面

### 三条反直觉

| 特征 | 爆款 | 冷门 | 结论 |
|---|---|---|---|
标题长度 | 33 字 | 34 字 | 无差异 |
标签数 | 5.0 | 4.7 | 无差异 |
含数字 | **15%** | **27%** | **数字反而更差** |

### 有效的

- **问句开场**：爆款 19% vs 冷门 10%
- **具体工具名**：爆款 Top15 里 10 条都点名
- **具体产出**：「丝滑动效」「高颜值网页」

**公式**：
```
[具体工具名] + [做某事像 X？] + [具体方案] + [具体产出]
```

## 六、封面层面

**264 条作品用同一套封面模板**，零例外：

紫色虚线边框 + 深色背景 + 白色粗体标题（2 行）
+ 绿色箭头配黄绿副标题 + 3D 卡通人物 + 左下角点赞数

**封面和数据无关**（同屏里 93~330 赞，模板一样）。
**它的作用是「账号识别」** —— 刷到任意一条，一眼知道是谁。

**我们做了四套完全不同风格的封面，观众刷到不会认为是同一个人做的。**

---

## 七、片内结构

5~6 个画面切换，每个 6.8~8.5 秒。
左上角真人头像（圆形，脸清晰，占宽 1/6）。
右上角固定标题栏，全程不动。
底部超大白色字幕，是唯一的口播载体。

**结构上爆款和冷门完全一样。所以结构不是变量。**

---

## 八、完整的运营模型

```
封面统一模板     →  观众记住你
片内固定结构     →  观众看得懂
画面里有正在发生  →  观众停下来
收藏率高         →  平台推流
```

**四条全中才会爆。**

我们现在：
- 封面：四套，无识别 ❌
- 片内结构：四种，不统一 ❌
- 画面里有正在发生：0 张 ❌
- 收藏率：未知 ❓

**四条里一条都没做到。**

## 九、可执行的三条

### 1. 选题硬标准（30 秒判断）

> 这条视频的画面里，**能有几个"正在发生"的时刻**？
> - 5 个以上 → 做
> - 1~2 个 → 数据一般
> - 0 个 → 别做

**"正在发生"举例**：录屏操作、代码在写、终端在跑、对话在滚、动画在放。

### 2. 视觉收敛成一套

不要四套风格。一套封面模板 + 一套片内结构，每期只填内容。

**账号识别是复利，每期重新设计是减法。**

### 3. 加固定标题栏

左上角常驻一行「这条在讲什么」。爆款和冷门都有，我们都没有。
成本极低，收益是"划到一半进来的人能立刻接上"。

## 十、不适合做的内容类型

按这份数据推断：

| 类型 | 为什么 |
|---|---|
| GitHub 项目介绍 | 画面静态，信息密度过高 |
| 教程/入门指南 | 成果要等很久才出现 |
| 工具合集 | 每个工具都没深入展示 |
| 省成本类（Token/钱） | 成果是"成本降低"，看不见 |
| CLI 工具 | 只有终端文字 |

## 适合做的

| 类型 | 画面里有什么"正在发生" |
|---|---|
| 录屏操作类 | 鼠标在动、界面在变 |
| 代码演示 | 代码在输入、终端在跑 |
| 对话演示 | 一问一答在滚 |
| 动画/视频生成 | 成品在播放 |
| 3D / 建模 | 模型在旋转 |
| 游戏 | 游戏在跑 |
